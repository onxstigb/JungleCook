# The Jungle Cook

## Project Description
The Jungle Cook is a responsive website created for N315 Homework 6. The project includes a Home page and a Login page, designed to match the provided prototypes across desktop, tablet, and mobile screen sizes.

## Features
- Responsive Home page layout
- Responsive Login and Sign Up sections
- Navigation between pages using JavaScript routing
- Responsive navigation menu for smaller screens
- Reusable header and footer
- SCSS styling organized into separate files

## Technologies Used
- HTML5
- SCSS / CSS
- JavaScript
- Vite

## Installation and Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/onxstigb/JungleCook
   ```

2. Navigate into the project folder:
   ```bash
   cd JungleCook
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
